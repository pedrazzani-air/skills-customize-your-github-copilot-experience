# 📘 Assignment: Python Testing with Pytest

## 🎯 Objective

Learn the basics of automated testing in Python by writing simple `pytest` tests for existing functions and checking common edge cases.

## 📝 Tasks

### 🛠️	Write Your First Pytest Tests

#### Description
Use the functions in `starter-code.py` and complete `test_starter.py` with basic test cases.

#### Requirements
Completed program should:

- Create tests for `calculate_total` using at least two scenarios.
- Create tests for `is_valid_password` with one valid and one invalid password.
- Run `pytest` and confirm all tests pass.

### 🛠️	Add Edge Case Tests

#### Description
Expand your tests to cover edge cases and improve confidence in your code.

#### Requirements
Completed program should:

- Add a test for `apply_coupon` using a valid code (`SAVE10`).
- Add a test for `apply_coupon` using an invalid code.
- Add at least one edge case test of your choice (for example, a zero value or short password).
